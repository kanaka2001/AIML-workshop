## 🖥️ Before Cloud Computing Existed

Before cloud computing, building software meant owning physical machines:

- Buy servers and networking hardware upfront
- Set up and maintain your own data center
- Hire a dedicated IT team to manage everything
- Estimate future traffic months in advance and buy excess hardware
- Pay for servers whether you use them or not

**Example:** If your college wanted to host a student portal, it would need to purchase physical servers, configure networking, and manage the hardware indefinitely.

---

## ⚠️ Problems with Traditional Infrastructure

| Challenge | What It Meant in Practice |
|---|---|
| High upfront cost | Small projects couldn't afford to even start |
| Hard to scale | Adding capacity required buying and setting up new hardware |
| Wasted resources | Servers sat idle most of the time |
| Slow deployment | Setting up new infrastructure could take weeks |
| Maintenance burden | Teams spent time managing hardware instead of building products |

---

## ☁️ What Cloud Computing Changed

> **Cloud computing** = on-demand IT resources delivered over the internet, with pay-as-you-go pricing.

Instead of owning infrastructure, you rent it from a cloud provider and pay only for what you use, only while you use it.

**The same student portal example — on the cloud:**
- Launch a server in 60 seconds from a browser
- Scale up automatically when 5,000 students register on deadline day
- Scale back down and stop paying when traffic drops
- No hardware to buy, configure, or maintain

---

## 📅 AWS Timeline

| Year | Milestone |
|---|---|
| Before 2006 | Organizations managed their own physical data centers |
| **2006** | AWS launches publicly — S3 and EC2 are the first services |
| 2010 | Amazon.com migrates its entire e-commerce platform to AWS |
| 2014 | AWS Lambda introduces serverless computing |
| 2017 | AWS adds AI/ML services: SageMaker, Rekognition, Polly |
| 2023 | Amazon Bedrock launches for Generative AI workloads |
| Today | AWS offers 200+ services used by millions of developers worldwide |

---

## 🧩 Five Key AWS Services — Quick Overview

| Service | What It Does |
|---|---|
| **Amazon EC2** | Virtual computers in the cloud — run any application |
| **Amazon S3** | Store and serve files, images, websites, and data |
| **AWS IAM** | Control who can access your AWS account and what they can do |
| **Amazon Bedrock** | Access powerful AI models for Generative AI applications |
| **Amazon SageMaker** | Build, train, and deploy machine learning models |
